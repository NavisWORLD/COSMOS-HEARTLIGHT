# HEARTLIGHT Therapy Usage Guide

## Read this first

HEARTLIGHT is not therapy by itself. In therapy or school-based related services, it is a **supporting interface** for communication, environmental observation, choice-making, and documentation. A qualified professional remains responsible for assessment, goals, interventions, safety, and scope-of-practice decisions.

## Three safe therapy-facing uses

### 1. Preference discovery
Use the child screen to learn which environmental or communication options a learner wants to try. Do not treat a button selection as a diagnosis.

### 2. Environmental experiments
Ask a narrow question such as: “Does reducing glare make reading more accessible right now?” Change one variable, ask the learner, and observe access to the activity.

### 3. Communication bridge
Use HEARTLIGHT alongside AAC or other communication systems when a learner needs an easy way to request quiet, movement, space, predictability, help, or another communication channel.

## The CST therapeutic-support loop

- **Perceive:** learner report + environment + observable context.
- **Compress:** summarize without diagnostic language.
- **Expand:** generate multiple possible supports.
- **Validate:** ask the learner and use professional judgment.
- **Express:** offer a clear, low-demand option.
- **Store:** retain only necessary, authorized notes.

## Never use the 12D support state as

- a symptom severity score;
- a diagnostic screen;
- proof of dysregulation;
- a treatment-response biomarker;
- a measure of autism, ADHD, trauma, anxiety, oppositionality, or intelligence;
- a reason to force a sensory intervention.

## Bio/sensor rule

HEARTLIGHT's reference app does not estimate pulse. The optional pulse box is manual information only. The camera module samples ambient room color/brightness and is not a physiological sensor.

Any future physiological adapter should be separately validated, consented, purpose-limited, and reviewed under applicable clinical/school rules before it affects care.

## Outcome rule

A support “worked” only when it improves access, communication, comfort, participation, or another agreed goal — not merely when the child becomes quieter or more compliant.
