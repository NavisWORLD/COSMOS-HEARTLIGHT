# 🌱 Guía del estudiante — HEARTLIGHT

HEARTLIGHT puede ayudarte a decir lo que necesitas sin tener que encontrar todas las palabras.

Puedes elegir opciones como:

- 🤫 silencio o menos sonido;
- 🌀 moverte;
- 🕯 menos luz;
- ↔ más espacio;
- 🧩 ayuda;
- 🌿 un descanso;
- 🧸 una opción de presión o trabajo corporal que ya sea segura y aceptada;
- 🎧 elegir el nivel de sonido;
- 🗓 saber qué va a pasar después;
- 💬 otra forma de comunicarte;
- ❔ “no lo sé”;
- 💚 “quédate conmigo”.

Puedes elegir más de una. **“No lo sé” también es una respuesta completa.**

## El temporizador

El temporizador visual es una herramienta que puedes usar para entender el tiempo. No debe usarse como castigo.

## El sensor de luz

El sensor opcional mira el color y el brillo de la habitación. La cámara debe apuntar a la habitación o a la luz, no a ti. HEARTLIGHT no decide qué color te debe gustar. Tu preferencia tiene prioridad.

## Tus datos

Tus selecciones de necesidades duran solo la sesión. Las notas del docente se guardan únicamente cuando un adulto pulsa **Guardar localmente**. HEARTLIGHT no necesita una cuenta en la nube para funcionar.

## Algo importante

La aplicación no decide si eres “bueno”, “malo”, “difícil” o si tienes un diagnóstico. Sirve para ayudar a las personas a escuchar mejor lo que necesitas para acceder, comunicarte y aprender.
