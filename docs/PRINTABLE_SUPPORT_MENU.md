# 🌈 HEARTLIGHT Quick Support Menu

Print or copy this page for classroom reference.

## I might need…

| Need | Gentle options to offer |
|---|---|
| 🤫 Quiet | quieter seat, reduce competing sound, approved hearing protection |
| 🌀 Movement | walk, stretch, wall push, safe movement seat, short movement break |
| 🕯️ Less light | reduce glare, dim screen, alternate seat, printed material |
| ↔️ More space | more physical room, smaller group, less crowding |
| 🌿 Break | predictable break with a clear return path |
| 🧩 Help me | one visible first step, model/example, reduced task chunk |
| 🗓️ Predictability | visual schedule, countdown, first→then, transition warning |
| 💬 Communication | AAC, typing, drawing, gesture, pointing, yes/no |
| 🧸 Body input | familiar consented proprioceptive activity; never forced touch |
| 🎧 Sound choice | preferred sound level, quiet option, approved headphones |
| 💚 Stay with me | trusted adult nearby, fewer words, learner controls distance |
| ❔ I don’t know | processing time, fewer choices, reduced demand |

## Three rules

1. **Ask rather than assume.**
2. **Offer rather than force.**
3. **Measure access, not obedience.**

## Neutral observation formula

```text
BEFORE / CONTEXT:

WHAT I COULD SEE OR HEAR:

SUPPORT OFFERED:

LEARNER CHOICE / RESPONSE:

WHAT HAPPENED NEXT:
```

## Stop using the menu and follow established school procedures for emergencies, serious safety risks, mandated reporting, or medical concerns.
