# HEARTLIGHT Portfolio & Product Guide

## What this repository demonstrates

HEARTLIGHT can be presented as a cross-disciplinary engineering project combining:

- product discovery and educator workflows;
- accessibility-first interface design;
- offline-first PWA engineering;
- C++17 library design;
- Rust library and FFI design;
- cross-platform architecture;
- deterministic state engines;
- privacy-by-design for sensitive educational contexts;
- CI/testing and open-source governance;
- technical writing for teachers, families, clinicians, administrators, and engineers.

## 60-second portfolio pitch

> COSMOS HEARTLIGHT is an open-source, local-first support platform for classrooms. It helps learners communicate immediate needs such as quiet, movement, reduced light, predictability, breaks, or another way to communicate. The same transparent 12-dimensional support-state contract is implemented in the web app, C++17, and Rust, with C ABI bridges for native platforms. It is deliberately designed not to diagnose children or automate discipline. The repository includes the application, native libraries, tests, privacy architecture, teacher manuals, family resources, study materials, and deployment documentation.

## Commercial paths

Possible paid offerings around the open project include implementation support, professional-development workshops, custom district integrations, accessibility-device adapters, private/on-prem administration, maintenance contracts, and supported native packaging.

Do not market the reference build as a medical device, psychotherapy product, diagnostic engine, guaranteed special-education intervention, or legal-compliance certification.
